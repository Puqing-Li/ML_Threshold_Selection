# Data and released resources

| Folder | Contents |
|---|---|
| `training/` | Five classifier-training tables and their voxel-size and expert-threshold configuration |
| `examples/` | LE01 worked input, four additional manuscript inputs, TomoFab-format example, and reference outputs |
| `released_model/` | Portable classifier bundle used for the reported LE01 thresholds |

Generated results and models trained by a user are written to the
runtime-created `outputs/` and `models/` folders at the repository root. They
are not part of the released resources.
